# LexExamBench

Independent benchmark infrastructure for Chinese legal qualification and historical judicial examination questions.

## Scope

This repository holds **source indexes, provenance and rights checks, benchmark schemas, and offline validation tooling**. It does not imply any license to copy, redistribute, or submit third-party examination questions or official answers to model providers.

- Public records: metadata and source URLs only unless all relevant rights are verified.
- Historical official answers are not automatically current legal answers.
- Confidential holdout contents must remain outside this public repository.
- A passing engineering check is not a professional legal review.

## Bootstrap

Project setup and offline tests will be added in LEB-01. No live provider calls or third-party datasets are required for CI.
