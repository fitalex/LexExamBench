# License policy — code and examination material are distinct

**No repository-wide license is granted yet.** The maintainer should independently approve an open-source license for wholly original LexExamBench code, with a follow-up PR.

This choice will **not** confer rights over official examination questions, answer keys, JEC-QA materials, training-provider collections, third-party compilations or other external resources.

## Permissions to evidence independently

1. Copy the question material.
2. Copy the answer material.
3. Retain the material in project storage.
4. Publicly redistribute or publish it.
5. Submit it to an external model provider for evaluation.

A public website or GitHub URL alone proves none of these. Treat each `pending` or `denied` grant as **not authorized**. `verified` requires a direct, recorded rights basis specific to the applicable version and use.

This repository initially stores **only source URLs and self-authored metadata**; no question or answer bodies. Any decision to add licensed excerpts, actual questions, a private Holdout set, or external-model runs requires a separate rights review and human approval. Never mark old answer keys as confirmed current law without expert review.
